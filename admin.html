Naya sansthan banayein

Location ke liye us sansthan ke andar khade hokar "Meri current location lo" dabayein (phone par, HTTPS link se). Sansthan banane ke baad Staff tab se staff ko us sansthan mein jodein. Har staff ki User ID apne aap banti hai: sansthan ke pehle 3 akshar (chhote) + 3 ank ka kram, jaise shr001, shr002. Is code se shuru hone wali ID kisi aur sansthan mein kabhi login nahi hoti. Do sansthan ke pehle 3 akshar same hon to ID Code mein alag 3 akshar likhein. ID Code ek baar ban gaya to badalta nahi. Staff app mein pehli baar login par sansthan chunta hai, par wo tabhi login hoga jab aapne use usi sansthan mein joda ho. Band kiya hua sansthan staff ko list mein nahi dikhta aur uske staff attendance nahi laga sakte.

Attendance mark karein (Admin)

Dhyan dein: Neeche se staff chunein (ek ya kai). Kai din chunne par Ravivar aur us staff ke sansthan ki chhutti ke din apne aap chhoot jaate hain; sirf ek din chunne par wahi din mark hota hai. Full day sirf aaj tak ki tarikh par ho sakta hai, CL/ML/Office Work aage ki tarikh par bhi. Mark kiye hue din staff Check In nahi kar sakta. Auto-out se Absent hue din ko Full day mark karke sudhaar sakte hain.

Staff chunein

Chhutti jodein

Ravivar apne aap saptahik chhutti mana jata hai. "Sabhi sansthan" chunne par chhutti sab par lagti hai. Chhutti ke din us sansthan ka staff Check In nahi kar sakta aur wo din Absent nahi ginta. Kisi se chhutti ke din kaam karwana ho to Attendance tab se Full day ya Office Work mark karein.

Report banayein

Report upar chune hue sansthan ki banti hai ("Sabhi sansthan" chunne par sab ki). Print dabane par "Save as PDF" chunkar PDF bhi bana sakte hain. Page A4 landscape mein set hai.

Naya Sansthan Admin banayein

Admin ID aur ek asthayi password server khud banata hai (password sirf ek baar dikhta hai). Pehli login par admin ko naya password rakhna padta hai. Sansthan admin sirf apne sansthan ka staff, attendance, chhutti aur report dekh/badal sakta hai; sansthan banana/badalna/band karna sirf Super Admin kar sakta hai.

Sansthan Admins

Gatividhi log (pichhli 300, sabse nayi pehle)

Yahan har zaroori kaam (login, staff jodna/hatana, attendance mark, chhutti, sansthan aur admin ke badlav, mana kiye gaye prayas) ka samay aur kisne kiya, ye likha hota hai. Password kabhi nahi likhe jate.

Apna password badlein

Password badalte hi baaki sabhi purane login (dusre phone/browser) turant band ho jate hain. Password sheet mein sidha nahi, salt ke saath chhupe (hash) roop mein save hota hai. Office ki location "Sansthan" tab mein (sirf Super Admin) set hoti hai.

Naya password set karein

Suraksha ke liye pehli login par (ya password reset ke baad) naya password rakhna zaruri hai.
